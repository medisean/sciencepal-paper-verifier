诚实结论（不设弱对手）：决定性的能力闸门是强制联网核验。离线模型只能凭"格式规律"猜测，漏掉格式最规范、最危险的编造 DOI（如 IEEE Access 风格的 10.1109/access.2019.2991190），又用臆想的期刊规则冤枉真实文献（Bentham 字母后缀、IJSR 编号）；一旦开放联网，普通 Agent 与专家工作流三项 F1 同为 1.000。我们没有用弱对手制造"专家流程更准"的假象，在撤稿、统计复算、2026 冷门撤稿限定任务三个同输入案例上，普通 Agent 也都做对。专家流程在当前强模型上的价值是确定性、效率与可审计：工具调用更少、无长期记忆污染、最终 JSON 稳定落在固定 schema。局限：仅单模型、n=48（全对时 Wilson 95% 下界约 0.926），弱模型上是否有增益尚未检验。
