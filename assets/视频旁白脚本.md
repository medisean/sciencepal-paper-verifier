## 分镜与旁白

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00–0:08 | 标题卡 | 大家好，我带来的作品是“科研论文核查员”——一个运行在 SciencePal 上的审稿 Agent，用可追溯证据替代模型“凭记忆猜测”。 |
| 0:08–0:24 | 问题（PPT 第2页） | 大模型撰写或审查文献时会编造 DOI、配错题录，甚至引用已撤稿论文。我们在 48 条金标准上实测：纯模型离线基线对幻觉 DOI 的 F1 只有 0.62，8 次误报、3 次漏报，漏掉的恰是格式最规范、最危险的伪造。 |
| 0:24–0:42 | 方案（PPT 第3页） | 我们的创新不是更大的模型，而是工作流：强制每条引用联网查询 Crossref，先验证 DOI 真伪（200/404），再逐字段比对题录，再识别撤稿，最后在沙箱里真实复算统计；所有 HTTP 状态、来源 URL 和复算脚本全部留痕。 |
| 0:42–0:55 | 公开回放 | 作品通过免登录的公开链接交付。评委打开即可看到完整的智能体运行记录，每一条沙箱命令都能回放、可复核。 |

| 1:13–1:33 | 最终报告 | 四条引用分别命中四种状态：真实放行、DOI 篡改、年份错配（Crossref 是 2024 年，引用写成 2027）、以及已撤稿。零误判。 |
| 1:33–1:50 | 撤稿案例 | 著名的 STAP 细胞论文 DOI 仍然有效，但标题带 RETRACTED 标记。Agent 主动查询 relation 字段，定位到官方撤稿通知；对正常文献则正确放行。 |
| 1:50–2:12 | 方法学复算 | 它还会在沙箱里装好 scipy，按原始数据复算。这篇虚构教学稿报告 p 值 0.03、0.04，复算却是 0.206、0.138，不显著；同时发现用两两 t 检验替代 ANOVA、样本量不足等问题，并产出可审计的复算脚本。 |
