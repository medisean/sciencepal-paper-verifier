# 腾讯问卷填写内容（可直接复制）

## 项目名称
科研论文核查员（Paper Reference Verifier）

## 项目方向
AI Agent（04）；应用场景以生物医学 / 健康类稿件为主，方法可迁移到任意学科

## 项目简介、科学问题与使用场景

【痛点】大模型进入写作流程后，引用失实被迅速放大：DOI 看似合法却不存在；DOI 真实但年份、作者、期刊、卷期页被张冠李戴；已撤稿论文仍被当作有效证据；报告 p 值与原始数据矛盾。人工逐条点开核对极耗时，通用模型“凭记忆”又分不清“不著名但真实”与“格式合法但伪造”，离线实测幻觉 DOI 检测 F1 仅 0.62，三项任务合计 23 次误报。

【做法】在 SciencePal 沙箱内构建核查 Agent：每条引用强制实际联网请求 Crossref，以真实 HTTP 200/404 判定存在性；对返回元数据逐字段严格比对；检查撤稿标题标记与 relation 撤稿关系；必要时在沙箱安装 scipy 复算统计量。所有结论附可点击证据 URL、HTTP 状态与复算脚本，输出中文报告加固定 schema 的 JSON。输入可以是一篇 PDF、一组 DOI 或一份参考文献清单，单次核查 12–36 条，逐条给出 DOI 状态、题录一致性、撤稿与统计问题，并给出总体风险评级。

【技术亮点】1) 强制取证，禁止凭记忆作答；2) 可复现金标准：评测集由脚本从 Crossref 实时构造，构造时即校验 404，并用 SSE 联网审计确保对照组公平；3) 代码级 guardrail：运行时拦截写记忆、反问等越权工具调用，强制“结构/覆盖/证据/自洽”四类交付契约校验，失败自动修复并留痕。稿件是不可信输入，提示词层的软约束挡不住。

【目标用户】期刊编辑与审稿人、研究生与论文作者、课题组与科研管理部门。

【使用场景】投稿前逐条自检参考文献；审稿时核验引用；一批稿件初筛高风险引用；结题材料与文献库清理。

【验证】48 条金标准、三方对照：离线 F1 0.62，联网后 1.000、误报 0；换 deepseek-v4-pro 复现 4/4；真实已发表论文的 50 条书目检出 4/4、误报 0；35 个 run 的契约回溯审计中专家流程 5/5 交付合规、普通联网 Agent 2/4；6 例稿件注入下交付可用率 4/6 提升到 6/6。

【价值】把“凭记忆判断”换成“可复核证据”，让论文核查可规模化、可审计、可复现。对期刊，可把引用核查从抽检变为全检；对作者，投稿前消除致命小错；对机构，结题与成果汇编可做合规检查。全流程在公开分享链接中免登录可回放。

## 核心使用环节与运行说明

【SciencePal 承担的核心工作】
不是用来写文案或做 PPT：每次取证都在 SciencePal 沙箱里真实执行（execute_command 请求 Crossref，必要时装 scipy 复算），平台负责工具编排、SSE 运行记录与回放；核查流程固化在 Agent 与代码级 guardrail 中（拦截越权工具、强制交付契约校验）。

【启动步骤】
路径一（零门槛）：打开主演示链接，点「跳到结尾」直接看最终报告，点「开始播放」按真实时间回放完整 39 步轨迹，每条沙箱命令与 HTTP 状态都可见，无需登录。
路径二（亲自运行）：新建对话 → 选 Agent「科研论文核查员」（agent_id: b5834007-2e4a-4c08-b9de-c4707c31e136）→ 粘贴下方示例 → 发送。4 条约 1 分钟，12 条约 1–3 分钟。

【示例输入】
[1] Lo C., Lee C., Huang W. (2020). Prognosis of Bearing and Gear Wears Using Convolutional Neural Network with Hybrid Loss Function. Sensors, 20, 12, 3539. doi: 10.3390/s20123539
[2] Tekcan Sanli DE., Sanli AN. (2025). Comment on “Breast lymphoma: Imaging features, clinical presentation, and ultrasound AI decision support”. Clinical Imaging, 127, 110621. doi: 10.1016/j.clinimag.2025.116202
[3] Rahimian P., Mihalyi BM., Toka L. (2027). In-game soccer outcome prediction with offline reinforcement learning. Machine Learning, 113, 10, 7393-7419. doi: 10.1007/s10994-024-06611-1
[4] Obokata H, Wakayama T, Sasai Y, et al. (2014). Stimulus-triggered fate conversion of somatic cells into pluripotency. Nature, 505, 641-647. doi: 10.1038/nature12968

【预期输出】
逐条判定表（DOI 200/404、题录逐字段一致性、是否撤稿、证据 URL）+ 总体风险评级 + 末尾固定 schema 的机器可读 JSON。上述四条应依次得到：放行 / DOI 不存在 / 年份错配（Crossref 为 2024，引用写 2027）/ 已撤稿（STAP，标题带 RETRACTED）。无法确证者标 suspect 并提示人工复核。

【访问权限】
三个链接均为「免登录、只读回放」，无需评审账号或额外授权。若需在评审期以可写方式实际运行该 Agent，请通过组委会联系我们临时开放（此处不填写任何账号、密码或 API Key）。
