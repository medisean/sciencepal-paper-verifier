# 原创性与资源使用声明

## 一、作品原创性声明

本人（个人参赛者）郑重声明：

1. 「科研论文核查员」Agent 的系统提示词、工作流设计、评测集构造方法、评测脚本、对照实验、技术报告、演示材料均为本人在 SciencePal 平台上独立完成的原创成果。
2. 本作品未抄袭、未剽窃任何他人作品；评测数据通过公开学术元数据 API（Crossref）以脚本自动、可复现地构造，金标准 DOI 状态在构造时实时核验，未人工标注或篡改他人数据。
3. 平台内置的 `verify-bib` 技能、SciencePal 沙箱与通用模型属于平台提供的公共能力，本作品的贡献在于**核查工作流设计、强制联网/证据留痕的工程约束、带金标准的可复现量化评测方法、以及对照实验设计**，而非声称平台底层能力为本人原创。

## 二、资源使用说明

| 资源 | 用途 | 来源 / 许可 |
|---|---|---|
| SciencePal 平台 | Agent 运行环境、隔离沙箱、联网、HTTP API、Python SDK | 主办方提供，按使用条款使用 |
| 通用大语言模型（平台自动路由） | Agent 推理与离线基线 | SciencePal 平台提供 |
| Crossref REST API | DOI 状态与论文元数据核验、评测金标准构造 | https://api.crossref.org（公开元数据，附带 User-Agent） |
| scipy（Agent 沙箱内临时安装） | 方法学案例的统计复算 | 开源（BSD 许可） |
| 示例论文 | 撤稿案例（Obokata STAP，公开出版记录）、LeCun 等真实 DOI 仅用于展示核验 | 公开可查的出版记录 |

## 三、数据与伦理

1. 评测仅使用公开的论文题录元数据（标题、作者、期刊、年份、DOI、卷期页），不涉及付费全文，不包含任何个人隐私信息。
2. 方法学/统计审查案例使用**明确标注为虚构的教学稿件**，未针对任何真实论文或真实作者作出负面评价，避免无据指控。
3. 撤稿案例仅客观引用出版记录中已公开的撤稿状态（Crossref 标题“RETRACTED ARTICLE”），用于学术诚信目的。
4. 本工具定位为**辅助审稿 / 作者自检**，对不确定项输出 `suspect` 提示人工复核，不替代同行评议与最终人工判断。

## 四、其他

- 本作品未使用任何未授权数据、未涉及人体试验或动物实验，无利益冲突。
- 所有运行记录、工具调用、HTTP 状态与复算过程均可通过公开分享链接与代码仓库复核。
